# Osirion

Sonho lúcido e viagem astral. App de Vivian Pupin com o método Arhat, do livro dela.

- Nomes dentro do app: Abaton é a prática da noite, Duat é o céu das noites (o diagrama de vivências).

Esta pasta é o projeto inteiro do Osirion, pronta para virar um repositório próprio no GitHub e um site próprio na Netlify. Enquanto estiver dentro do repositório da Caravana, nada daqui é publicado (o Netlify da Caravana publica só a pasta `app` da raiz).

- `app/`: o aplicativo (abre no celular e pode ser instalado na tela inicial).
- `netlify.toml`: só publica quando o commit tiver `[publicar]`.
- O que a pessoa anota ainda fica só no aparelho. A próxima etapa é a conta na nuvem.
